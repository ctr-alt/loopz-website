FAQ

Frequently asked questions

Clear answers based on verified LOOPZ project information. Where details need confirmation, they are marked.

What is LOOPZ?

LOOPZ is an Android app for downloading, organizing, browsing, and editing media. It includes features such as Media Library, Offline vertical video Feed, Media Studio, and Download Manager.

Which platforms currently work?

Instagram video/Reel downloading and X video downloading are currently supported in LOOPZ 1.1.0. Facebook and other platforms are not currently supported unless explicitly stated in future updates.

How do I install the APK?

Download the official APK from the Download page once the official link is configured, verify the release metadata and SHA-256 checksum, allow installation from the trusted source if Android prompts you, then install and open LOOPZ.

Is Facebook supported?

No. Facebook is not currently supported in LOOPZ 1.1.0. It may be added in a future update, but it should not be considered available until officially announced and supported.

Where are downloaded videos stored?

Downloaded media is stored locally on your device through Android storage/media flows used by the app. The exact user-visible folder/path behavior can vary by Android version and app flow; confirm the final user-facing storage location details before publishing support documentation.

Does LOOPZ require an account?

No evidence of user accounts or a LOOPZ backend was found in the audited repository. LOOPZ is designed as a local Android app experience.
